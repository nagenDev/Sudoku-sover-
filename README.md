# 🔢 Sudoku Solver (Java + Swing)

A **Java Swing-based Sudoku Solver** that visualizes the solving process in real time using backtracking.  
The program updates the grid as it searches for the solution, showing each placement and backtrack step.

---

## 🚀 Features
- ✅ **Automatic Sudoku Solving** using backtracking algorithm.  
- 🎨 **Graphical UI with Swing** – 9×9 grid of buttons.  
- ⏱️ **Real-time Visualization** – step-by-step updates while solving.  
- 🧩 **Backtracking Animation** – see how the algorithm explores possibilities.  
- 📄 **Preset Puzzle** included in code (can be changed).
